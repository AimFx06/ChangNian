# 常念接口说明

统一响应格式：

```json
{
  "success": true,
  "message": "ok",
  "data": {}
}
```

除 `/api/auth/**` 和 `/api/health` 外，接口需要请求头：

```text
Authorization: Bearer <token>
```

## 认证

### 登录

`POST /api/auth/login`

```json
{
  "username": "child",
  "password": "16888"
}
```

### 注册

`POST /api/auth/register`

子女账号不传 `familyCode` 时会创建新家庭；老人账号需要传家庭邀请码。

```json
{
  "username": "new_child",
  "password": "123456",
  "displayName": "林晓",
  "role": "CHILD",
  "phone": "13800000000",
  "gender": "女",
  "familyCode": ""
}
```

## 首页

### 子女端首页数据

`GET /api/home/child`

返回周报、近期状态、话题卡、老人回应、回忆、用药和 SOS 记录。

### 老人端首页数据

`GET /api/home/elder`

返回待回应递话筒消息和内置用药提醒。

## 递话筒

### 子女端创建递话筒

`POST /api/topics/{topicId}/microphone-requests`

```json
{
  "elderUsername": "mother"
}
```

`elderUsername` 可传 `mother` 或 `father`；不传时兼容旧流程，默认递给当前家庭第一个老人账号。

创建后会通过 WebSocket 向老人端推送：

```json
{
  "type": "MIC_REQUEST_CREATED",
  "payload": {}
}
```

### 老人端回应

`POST /api/elder/messages/{requestId}/responses`

```json
{
  "content": "我挺好的，今天下楼走了两圈。",
  "audioUrl": ""
}
```

回应后会通过 WebSocket 向子女端推送：

```json
{
  "type": "ELDER_RESPONSE_CREATED",
  "payload": {}
}
```

## 用药

### 记录已吃

`POST /api/medications/{scheduleId}/taken`

### 记录待会吃

`POST /api/medications/{scheduleId}/later`

## SOS

`POST /api/emergencies`

```json
{
  "locationText": "老人端手机当前位置待接入",
  "note": "老人端点击 SOS"
}
```

创建后会通过 WebSocket 向子女端推送：

```json
{
  "type": "EMERGENCY_CREATED",
  "payload": {}
}
```

## 文件上传

`POST /api/files/upload`

表单字段：`file`

返回：

```json
{
  "url": "/uploads/20260704/xxx.png"
}
```

## AI

### 生成周报

`POST /api/ai/weekly-report`

```json
{
  "signals": ["爸爸这周去了三次公园", "周三提到腰酸"]
}
```

### 生成话题

`POST /api/ai/topics`

```json
{
  "signals": ["爸爸最近经常提到李叔叔", "妈妈提到老家槐树"]
}
```

### 生成并刷新 AI 数据

`POST /api/ai/insights/refresh`

按当前选择的妈妈/爸爸，从后端数据库收集最近留言、用药记录、就诊记录、每日近况、话题卡和“说过的事”，调用 DeepSeek 生成并写入：

- `weekly_reports`：周报
- `daily_statuses`：每日近况
- `topic_cards`：话题卡
- `family_memories`：说过的事

返回 `mocked=false` 表示本次是真实 DeepSeek 生成；未配置 `DEEPSEEK_API_KEY` 时返回本地兜底数据，`mocked=true`。

兼容路径：`POST /api/ai/topics/refresh` 也会触发同一套刷新逻辑。

```json
{
  "elderUsername": "mother"
}
```
