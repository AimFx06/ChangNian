# 数据库设计

数据库名：`changnian`

后端启动时通过 `schema.sql` 自动创建表。

## 核心表

### families

家庭表。保存家庭名称和邀请码。

### users

用户表。支持 `CHILD` 和 `ELDER` 两种角色。密码使用 BCrypt 哈希存储。

### weekly_reports

周报表。保存 AI 或种子数据生成的本周叙事、关键词和摘录。

### daily_statuses

近期状态表。保存近况页时间轴。

### topic_cards

话题卡表。保存 AI 生成或内置的话题引子。

### microphone_requests

递话筒请求表。子女点击递话筒后创建，老人端读取 `PENDING` 状态。

### elder_responses

老人回应表。老人提交文字或录音后写入，并同步给子女端。

### medication_schedules

内置用药提醒表。第一版由种子数据生成。

### medication_records

用药记录表。保存 `TAKEN` 和 `LATER`。

### emergency_events

SOS 事件表。老人端三秒倒计时结束后写入，并通知子女端。

### medical_records

就诊记录表。第一版预留，用于后续录音、处方单、化验单上传归档。
