# 第一版演示流程

1. 启动后端，确认 `http://127.0.0.1:8080/api/health` 返回 `UP`。
2. 启动前端，打开 `http://127.0.0.1:5173/` 或局域网 Network 地址。
3. 用 `child / 16888` 登录子女端。
4. 查看近况页周报和近期状态。
5. 进入话题页，选择一张话题卡，点击“递话筒”。
6. 另一个浏览器或手机用 `father / 16888` 或 `mother / 16888` 登录老人端。
7. 老人端看到新消息，输入回应并点击“发给闺女”。
8. 子女端话题页收到实时回应。
9. 老人端点击用药“吃了”或“待会吃”，后端写入用药记录。
10. 老人端点击 SOS，等待三秒倒计时结束。
11. 子女端收到 SOS 横幅提醒。
