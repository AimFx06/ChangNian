# 核心功能调用大模型代码说明

“常念”的大模型调用集中在 Spring Boot 后端，前端不保存、不暴露 DeepSeek Key。

## 核心文件

- `changan-server/src/main/java/com/changnian/service/AiService.java`
  - 真实调用 DeepSeek Chat Completions 接口。
  - 生成周报、每日近况、话题卡、老人端递话筒转述、说过的事。
  - 结构化输出使用 `response_format: {"type":"json_object"}`。
- `changan-server/src/main/java/com/changnian/service/AiInsightService.java`
  - 汇总当前老人最近留言、近况、说过的事、用药提醒、用药记录、就诊记录。
  - 调用 `AiService` 生成并写入周报、每日近况、话题卡和记忆。
  - 明确按当前 `elderId` 过滤，妈妈/爸爸数据不混用。
- `changan-server/src/main/java/com/changnian/controller/AiController.java`
  - 暴露 `/api/ai/topics/refresh` 和 `/api/ai/insights/refresh`。
- `changan-server/src/main/java/com/changnian/service/MemoryService.java`
  - 老人回复后生成“说过的事”，寒暄短句不会进入回忆。

## 环境变量

```env
DEEPSEEK_API_KEY=填入真实Key
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-v4-flash
```

未配置 `DEEPSEEK_API_KEY` 时，接口使用本地兜底内容保持演示可运行，并返回 `mocked=true`。配置真实 Key 后，生成结果返回 `mocked=false`。

## Prompt 设计要点

- 周报：只基于最近 7 天真实信号，不做诊断，不制造焦虑，输出标题、摘要、关键词和引用。
- 每日近况：按日期范围生成，每天最多一条；没有足够信号时使用克制表达，不编造故事。
- 话题卡：根据最近留言、近况、用药记录、就诊记录、说过的事生成 5 张卡，刷新时避开已有角度。
- 递话筒：把子女端话题改写成老人端能直接听懂的一句话，重点做人称转换，例如“她看了吗”转成“你看了吗”。
- 说过的事：先判断是否值得记录，“晚上好、好的、嗯、谢谢”等寒暄不会入库。

## 官方接口依据

DeepSeek 官方文档列出 `https://api.deepseek.com` 作为 OpenAI 格式 Base URL，当前模型包括 `deepseek-v4-flash` 和 `deepseek-v4-pro`。JSON 输出按官方要求设置 `response_format`，并在 prompt 中包含 JSON 示例。
